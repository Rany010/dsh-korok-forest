# V3 验收记录

2026-11-14。开发分支 `feat/v3-forest-scenes`。

## 实现

接入设计包的四张 WebP 运行素材。完整森林用于首页，透明边缘素材用于已有会话。会话场景在宿主可调阅读宽度外绘制，阅读区域采用实体底色。场景绝对定位、点击穿透，强度仅作用于场景层。

通过宿主 `theme.overrideTokens` 注入浅色和深色资源对，随外观即时切换。沿用项目既有 data URL 打包方式，资源包含在 `lib/client.js`，无需额外静态服务器。插件卸载时撤销主题覆盖和样式。

背景默认开启，强度默认 62%，支持 0–100% 调节和简约阅读。旧 schemaVersion 1 设置自动补齐新字段。低动态关闭呼吸效果。桌宠气泡约四秒后隐藏，位置按实际输入区高度和窗口高度约束。

## 验证结果

- `npm run build` 成功。构建依赖已锁定，支持 Windows。
- `node --test` 30 项全部通过，包括原有 28 项和新增设置迁移、边界值回归。
- Chrome 组件夹具验证通过。1280×720、1440×900、1920×1080，各自覆盖浅色/深色 × 首页/会话，共 12 种组合。检查输入、滚动时场景稳定、桌宠避开输入区、关闭背景、简约阅读、低动态及刷新后设置持久化。
- 实际安装为 `E:\DSH` 的 DeepSeek Harness 0.2.2-rc.3。插件已通过官方 CLI 链接到 desktop profile 并生效。
- 实际窗口确认晨光首页、幽光首页、背景关闭与恢复、森林设置入口、设置实底和输入焦点。主题验证后恢复「跟随系统」，背景恢复默认 62%。观察截图已在开发对话中呈现。

## 本机安装和回退

```powershell
& 'E:\DSH\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add E:\coder\code\dsh-korok-forest
```

通过「设置 → 呀哈哈森林 → 背景显示」可关闭场景。完整卸载使用官方命令。

```powershell
& 'E:\DSH\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop remove dsh-korok-forest
```

本地设置沿用 `dsh-korok-forest/v1`。卸载保留设置，可通过插件设置页的「清空本地数据」清除。
